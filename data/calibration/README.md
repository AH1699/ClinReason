# Prospective calibration drafts

`multiturn_candidates_v1.json`, `multiturn_candidates_batch_b.json`, and `multiturn_candidates_batch_c.json` contain **ten bilingual, two-turn author drafts** prospectively reserved for calibration. All three are deliberately absent from `config/benchmark.json`'s default development case list. Their paired provenance files record published-case mechanisms, public clinical sources, adaptations, and limits. The cases are synthetic, not copied patient records; Chinese text and clinical labels are unreviewed.

This directory is **not** a scored or approved Gold set. Do not run these cases for a model leaderboard, tune a judge against its own answers, or merge them into the public development set. See the [current S5 tranche record](../../docs/S5_CALIBRATION_TRANCHE_2026-10-19_EN.md) and `python3 -m benchmark.portfolio_audit` for split/integrity status. The hidden candidate is intentionally absent from Git; approved calibration and hidden Gold counts remain zero.

`criterion_anchors_v1.json` / `response_contrasts_v1.json` cover the first six families; `criterion_anchors_batch_c.json` / `response_contrasts_batch_c.json` cover the four batch-C families. Together they form **two provisional, hash-bound bilingual scoring packets for all ten drafts**, with 20 anchored language variants and 60 controlled update responses. The [batch-C packet record](../../docs/S5_CALIBRATION_PACKET_C_2026-10-19_EN.md) explains the new boundaries. Their clinical content, translation and intended response ordering have **not** been independently adjudicated. None is in the default runner; no calibration response has been model-scored.
