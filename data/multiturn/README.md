The configured public multi-turn development track has **51 families / 102 English/Chinese conversations**, all draft and unreviewed. The scripted second user message is withheld until the candidate answers the first. This track is **not** part of the 32-family/64-prompt single-turn Alpha, and its scores must not be pooled into that Alpha average. New prospective calibration drafts live in [`../calibration/`](../calibration/), outside the default runner; hidden draft material is local-only, not in Git.

The two languages share error IDs and severities, but semantic equivalence has not been human reviewed.
