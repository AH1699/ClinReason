# 在哪里找病例和答案，以及下一批怎么扩充

目前公开草稿共有 **135 个不同病例族**：125 个已登记到开发集，另外 10 个属于尚未登记的 O、P、Q、R 批次。每族各有中英文版本，不能按两道独立病例计算。目录只提供统一入口，不会自动把独立草稿加入测试，也不改动旧实验。校准候选、确认集和西安私人病历不计入这 135 个。

## 查找病例和答案

在项目目录运行：

```sh
python3 -m scripts.authoring_catalog --summary
python3 -m scripts.authoring_catalog
```

第一条显示数量；第二条逐项列出病例编号、所属方向、是否已登记、文件位置、中英文版本、内容哈希、来源和答案字段位置。新增的[目录配置](../config/authoring_catalog_v1.json)负责列出独立草稿批次；哪些数据属于已登记开发集，仍以原有的[基准配置](../config/benchmark.json)为准。

| 病例方向 | 现有数量 | 去哪里看答案标准 |
|---|---:|---|
| Alpha 单轮问答 | 32 个已登记病例族 | JSONL 中每条病例的 `reference_answer`、`critical_requirements`、`critical_errors` |
| 患者多轮对话 | 51 个已登记病例族 | 每一轮的必答要求和严重错误；真正评分时，还必须明确选择并冻结与病例版本匹配的评分边界 |
| 专业临床任务 | 42 个已登记病例族 | 各语言版本的 `reference_elements` 和 `critical_errors`；暂未开放专业任务评分 |
| O、P、Q、R 独立草稿 | 10 个未登记病例族 | 病例、评分边界、参考回答、对照回答和来源映射分别保存，见下方链接 |

[O 批次](BATCH_O_STANDALONE_ZH.md)讨论液体负荷与肾功能之间的取舍，以及营养补充后的电解质变化。[P 批次](S54_LIVE_ADMISSION_AND_BATCH_P_ZH.md)讨论血小板计数不可靠、诊室与家中血压不一致。这些答案目前都是作者草稿，不代表已有临床专家认可；它们也没有自动进入当前评分实验。

## 下一批具体做什么

长期目标仍是 **至少 500 个不同病例族**。按现有公开草稿计算，还需要增加 365 个。翻译、改写措辞、同一病例的强弱回答对照，都不算新增病例。数量达标和可以对外发布，是两件不同的事。

[S64／R 批次](S64_DEVELOPMENT_CALIBRATION_ZH.md)新增低钠检测偏差伴真实血脂风险，以及疑似 ACE 抑制剂肠道水肿后的再用药边界。[题目](../data/authoring/batch_r_cases.json)、[锚点](../config/multiturn_criterion_anchors_batch_r_v1.json)、[对照回答](../data/authoring/batch_r_contrasts_v1.json)和[来源记录](../data/authoring/batch_r_provenance.json)放在旧实验扫描范围之外。H153／H154 未结案；运行 `python3 -m scripts.audit_batch_r` 只能检查结构，不产生模型分数或难度结论。

[Q 批次](S59_BATCH_Q_CASE_EXPANSION_ZH.md)已完成原定四个新问题。S60／S61 绑定并演练了 O／P／Q 八族；单独获批的 S62 现已收束，见 [S63 结果](S63_STANDALONE_PILOT_RESULTS_ZH.md)。目前有 39 格首评总分和六格完整复评，输出耗尽及引用格式失败均保留。这些工作没有自动登记或增加病例族。扩题继续独立推进：根据读数找需要核查的答案要求，不回头改已测病例，也不为显得困难而凑分。重点仍是多种解释、病程变化、治疗利弊和改变行动的新证据。患者问题不要点破结论，并保留应当克制处理的场景，避免“一律急诊”成为得分捷径。

每个病例交付一套完整材料：自然的中英文对话、分轮次的预期行为、可接受的其他答法、拟定严重错误、参考回答及有控制的遗漏示例，并逐项说明答案要求由哪条公开证据支持。真实发表病例用于提取临床机制和决策过程，不直接充当新病例的标准答案。来源本身不能解决的问题、语言歧义和临床不确定性，边写边记入后续专家审阅清单。公开草稿不带患者身份信息，也不复制原始病历图片。

新批次进入实验前，先核对是否与已有开发集或预留集重复，再检查病例与答案的版本绑定，并单独冻结实验材料。不修改旧实验，也不为了让低档模型落在 60–70 分、平均约 80 分、高档约 90 分而倒推标签。这些数字仍是观察目标。临床和双语专家审阅可以后置，但没有取消。

目录检查只证明数量、编号、语言配对和文件位置等结构正确，不证明病例医学正确、足够困难或可以发布。
