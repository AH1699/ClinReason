# S18 同一输入包裁判可重复性预注册 — 2026-10-21

**问题：**现有裁判流程重复评审*同一份* `REASON-015` 答案输入包时，逐条件状态、维度分、暂定通过及人工复核请求是否一致？[S17 存档结果](S17_CLEAN_PROBE_RESULT_2026-10-21_ZH.md)提供第一次观察。[S18 方案](../config/judge_repeatability_s18_v1.json)、[有限运行器与比较程序](../benchmark/judge_repeatability_s18.py)规定**八个单元各重复一次**：基线与删除安全提醒的答案 × 英中两种语言 × Gemini 3.8 Flash 和 Grok 4.7。案例、答案、锚点、量表、裁判提示及模型名单哈希不变。不得调用候选模型或自动重试；新增调用上限为 **8**。原始响应留在 Git 忽略的本地目录。S17 来源报告的哈希在任何 S18 调用前已冻结于方案。

适配器未传入 temperature、top-p 或 seed，而使用服务商默认设置。核查实际返回的模型身份及适配器代码哈希，但不能排除服务商侧模型或服务变化。八次上限限制计费请求次数，**不是可保证的金额上限**；项目没有账单遥测。若请求失败或送达状态不明，应停止并保留部分记录，不得暗中重试或拼成完整样本。

独立审计将重算两次运行，并逐一报告准确对应单元的分数差，以及实际模型身份、逐条件状态、要求／安全／修订维度、通过标记、裁判请求复核是否一致。它会计数准确重复，但**不会**平均或改写分数、估计错误率、宣称临床正确性或排列候选模型。每单元只有两次观察，因此只是可重复性冒烟测试，不是信度系数或调整阈值的依据。专业临床及双语审核虽推迟，临床声称前仍必需完成。约 60–70／80／90 的模型期望分段不作拟合。

可运行 `python3 -m benchmark.judge_repeatability_s18 plan` 离线核查固定方案。实时命令需要显式提供新的输出目录及 `--max-api-calls 8`；预注册时尚未运行。
