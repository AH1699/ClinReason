# 案例覆盖扩展路线 — 更新于 2026-10-19

**当前检查点：**[S6 开发集缺口审计及患者 F 批次](S6_DEVELOPMENT_GAPS_BATCH_F_2026-10-19_ZH.md)使公开草稿库达到 **108 个双语案例族／216 个语言版本**：Alpha 32、患者双轮 34、专业 42。下方 104／30 的计数属于历史批次。13 道双轮分诊题中有 11 道最终升级为急症，没有最终为常规或自我护理的题；稳定低紧急度及真正降级的对照是下一编写重点。与潜在合作伙伴讨论期间，独立临床及双语审核延后而非取消；获批校准／隐藏 Gold 仍为 0／0。

目前 Global Core Alpha 有 **32 个双语案例族 / 64 条题目**：分诊七族，其他五类各五族。[第一批](LABEL_EXPANSION_2026-10-11_EN.md)和[第二批](LABEL_EXPANSION_BATCH_B_2026-10-11_EN.md)在最初 12 族之外增加了 18 族；2026-10-12 又新增两组低紧急度分诊对照，旧题目未改动。这仍只是管线和编写试点，不足以衡量复杂临床推理或专家级知识。把中文译本当作第二个独立临床场景，会高估覆盖面。现有案例仍是单轮、面向患者的情境。公共数据源与许可注意事项见[英文清单](PUBLIC_DATASET_SOURCES_EN.md)。

机器可读的[覆盖审计](../benchmark/coverage.py)已确认：32/32 个案例族均面向患者且为单轮；分诊分布为急症 4、需及时处理的非急症 1、常规 1、自我护理 1。新案例用于测试避免过度分诊，但每个低紧急度单元只有一族，覆盖仍薄弱。作者标注的推理标签只是**拟测试能力，不是实测难度**。本轮进展见[项目记录](PROJECT_PROGRESS_2026-10-11_ZH.md)。

另有[独立的脚本化两轮试点](MULTITURN_PILOT_2026-10-11_ZH.md)、[C 批次](MULTITURN_BATCH_C_2026-10-11_ZH.md)、[D 批次](MULTITURN_BATCH_D_2026-10-12_ZH.md)和 [E 批次](BATCH_E_100_FAMILIES_2026-10-14_ZH.md)，合计 **30 个草稿案例族、60 段对话**。新增内容测试过敏、高温、血栓及眼症状的升级分诊，抗凝者头伤后的重评，用药风险，以及 ANA/乳糜泻检查解释。该轨道仍为合成、未经审核，不计入单轮分数；案例数不证明难度。

三个有意分离的轨道现共 **104 个不同的双语案例族**（Alpha 32 + 双轮 30 + 专业 42），即 208 个语言变体。不得混合成一个临床总分。[F 批次案例库审计](PORTFOLIO_AUDIT_BATCH_F_2026-10-15_ZH.md)列出新增构念、重叠与来源—标签清单、前瞻性分组计划及审核门槛。

## 增量之前先区分能力

1. **面向患者的 Global Core：**不假设某国医疗服务的安全分诊、澄清、用药边界、结果解释、隐私与不确定性。已超过 **30 个案例族的首个覆盖里程碑**；继续扩至 50 或 500 应依据覆盖和审核标准，而不是把数量当作统计充分性的证明。
2. **面向临床专业人员的独立轨道：**[原十族试点](PROFESSIONAL_PILOT_2026-10-12_ZH.md)、[E 批次](BATCH_E_100_FAMILIES_2026-10-14_ZH.md)与 [F 批次](PORTFOLIO_AUDIT_BATCH_F_2026-10-15_ZH.md)现有 **42 族、84 题**：临床咨询 28、用药核对交班 7、证据评价 7。26 族重新编写自不同的 CC BY 病例报告，并记录署名和局限；其余是合成的证据或指南场景。文书及更广泛的研究综述仍是缺口。患者轨道高分不代表专家临床能力；专业评分仍未启用。
3. **司法辖区包：**本地指南、药物、转诊路径、筛查安排与生效日期。不得把这些内容混入 Global Core 并当作全球正确答案评分。

[HealthBench 研究](https://arxiv.org/abs/2505.08775)使用多轮对话和医生为每例制定的评分标准评估开放式医疗行为。[HealthBench Professional](https://arxiv.org/abs/2604.27470)聚焦临床咨询、文书及医学研究，由医生编写并裁决。这些只是方法学实例，**不能**证明本项目现有案例或分数与其可比。[OpenAI 官方评测指南](https://developers.openai.com/api/docs/guides/evaluation-best-practices)也强调与任务相符的覆盖面和人工校准，而非仅增加题目数量。

## 优先覆盖缺口

| 缺口 | 新草稿案例族应测试什么 | 必要控制 |
|---|---|---|
| 连续推理 | 初步回答后出现新信息时，模型是否恰当修正鉴别思路或紧迫性 | 扩展案例契约以容纳多轮输入；由临床医生审核各分支 |
| 竞争风险与多病共存 | 冲突症状、多种慢性病、多药联用、禁忌证不确定性 | 相应专科医生/药师审核；不编造个体化剂量规则 |
| 纵向数据 | 合成化验趋势、互相矛盾的记录、缺失单位/参考范围、危急值处理 | 检验医学审核与明确的数据来源 |
| 证据与指南评估 | 来源相互冲突、过期、质量低或依赖司法辖区；何时保留判断或要求本地政策 | 来源日期、适用范围及不确定性需与记忆性知识分开评分 |
| 专业工作流 | 诊疗咨询、交接摘要、文书、文献综述 | 独立的临床专业构念、角色及量表；不与患者轨道混成总均值 |
| 稳健性与公平性 | 中英文语义等价、健康素养、无障碍、资源限制、对抗指令 | 双语临床审核和偏差检查；避免人口特征刻板印象 |

## 编写顺序与发布边界

- [历史 104 族审计](PORTFOLIO_AUDIT_BATCH_F_2026-10-15_ZH.md)列出部分机制重叠及来源—标签风险；[当前 108 族检查点](S6_DEVELOPMENT_GAPS_BATCH_F_2026-10-19_ZH.md)新增覆盖和已保存评审诊断，但不是临床去重或难度验证。校准集与隐藏集必须是前瞻新增的题；现有公开题仍全部属于开发集。
- 后续应优先审核全部 32 个 Alpha、34 个双轮及 42 个专业案例族的临床与语言问题，从三级关键错误规则及高优先级来源—标签清单开始。当前只是推迟审核，并未免除。
- 按使用者角色、工作流、紧急程度、难度、语言、专科及司法辖区建立覆盖矩阵；按不同失败模式选题，而不是凑改写数量。
- 用公开证据和合成事实试写少量高级案例族。AI 可协助起草与审查，但临床参考答案和错误严重程度须由合格临床医生确定；语言等价性须由合格双语审核者批准。
- 每个高级案例族应明确可区分的失败模式、看似合理但不安全/不完整的回答，以及强答案的可观察特征。叙述变长不等于复杂。连续推理需受控新消息；多病共存需在明确缺失信息下作出真实的竞争风险判断。
- 将开发集、评审模型校准集与隐藏 Gold Set 分开。改变含义的修改需要新版本并重新审核。公开类别比较前由统计人员确定样本量和不确定性目标。
- 不公布把面向患者和面向临床专业人员任务混在一起的“专家临床推理”单一分数。应分别报告轨道、类别、语言、关键错误率和不确定性。
