# S18 exact-packet judge repeatability preregistration — 2026-10-21

**Question:** Under the present judge workflow, do repeated evaluations of the *same* `REASON-015` answer packet yield the same criterion statuses, dimension scores, provisional pass and review request? The [S17 saved report](S17_CLEAN_PROBE_RESULT_2026-10-21_EN.md) supplies the first observation. This [S18 protocol](../config/judge_repeatability_s18_v1.json), [bounded runner and comparator](../benchmark/judge_repeatability_s18.py) specify exactly **one new repeat of each of eight cells**: baseline and omitted-safety-net answer × English and Chinese × Gemini 3.8 Flash and Grok 4.7. The case, answer, anchors, rubric, judge instruction and roster hashes are unchanged. No candidate calls or automatic retries are permitted; the new-call cap is **8**. Raw responses will remain local and Git-ignored. The S17 source report hash is frozen in the policy before any S18 call.

The adapters omit temperature, top-p and seed and use provider defaults. Returned model identities and adapter-code hashes are checked, but provider-side model/service drift cannot be ruled out. The eight-call limit constrains the number of billable requests, **not a guaranteed monetary total**; the project has no billing telemetry. If a request fails or its delivery is uncertain, stop and preserve the partial artifacts—do not silently retry or combine them into a complete panel.

The independent audit will recompute both runs and report, for every exact cell, the score delta and whether returned model identity, criterion statuses, requirement/safety/revision dimensions, pass flag and judge-requested review match. It will count exact matches but will **not** average or overwrite scores, estimate an error rate, claim clinical correctness, or rank candidate models. With only two observations per cell, this is a smoke test of repeatability, not a reliability coefficient or justification for a scoring threshold. Expert clinical and bilingual review is still deferred but mandatory for clinical claims. The ~60–70/~80/~90 aspirational model bands remain unfitted.

Use `python3 -m benchmark.judge_repeatability_s18 plan` to verify the no-network fixed plan. The live command requires an explicit fresh output directory and `--max-api-calls 8`; it has not been run at preregistration time.
