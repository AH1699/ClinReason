# 离线运行可重放，O 批次新增判分草稿

九题族流程现在不只在内存中演练，也能逐次保存请求与回包，再从磁盘重建结果。O 批次的两处边界另起了版本，共备好 **18 份中英文对照包**。本轮没有调用模型、产生新成绩或增加登记题数，旧实验和 O 批次原文件都保留原样。

## 中断之后能查清什么

[保存程序](../scripts/mixed_capture_s52.py)每次只能新建一个本地目录。它先绑定输入和导入的旧回答，保存本次请求记录与完整请求内容，随后先存回包字节，再解析回答、核算模拟费用并记录是否接收。写盘或解析出错后，该运行对象不能继续接收回包，也不能当成一次重试。

完整模拟覆盖原定 **452 次请求**：128 个新回答回合、36 次对照判断、144 次首评、144 次同请求复评。所有 **72 段对话、144 个回答回合**都保留，其中八段用药对话仍有比较结论待审标记。16 个旧回答直接导入，不重新生成。这是程序演练的数量，不是又拿到了 452 次模型回复。

重放时不直接相信保存好的分数或状态，而是从回包重新解析，并核对请求、跳过的任务、用量、停止原因和最终记录。改过的请求或回包、缺号、多余文件、链接文件，以及停止后又出现的请求，都会被拒绝。重放沿用原调度和解析规则，所以这里的“独立”指重新读取和核对原始记录，**不代表另一位临床评判者**。

遇到尾部记录不完整时，按以下方式处理：

- 只有请求记录、没有完整回包收据，明确标为未解决；即便有部分字节，也不拿它凑出回答或费用。
- 已保存完整回包收据、但来不及写结果，可以离线重建供检查；不补写原记录，更不会自动续跑。
- 模拟费用无法核实时，全局停止。费用可核实但回答不合格时，关闭该模型通道；缺失成绩仍是缺失，不算零分，也不从面板中删掉。模拟费用阈值允许最后一次请求超出。

测试用导入回答会明确标注“未核验历史来源”。另一条导入路径会先重放实际的 S45／S46 本地记录，核对既定哈希；检查新记录时还会重新核验。已用真实旧回答库加一个模拟回包检查这条路径，没有公开旧回答正文或模型内部推理。

当前仍是**离线保存器**：只接收已提供的字节，不读密钥，也没有发 HTTP 请求的接口。网络超时、真实响应截断等情况，还要在另起版本的网络适配器里通过模拟传输测试。这里的费用阈值不是新的付费授权，也不保证硬性封顶。

## O 批次这次怎样改

[新草稿](../data/audit/batch_o_wording_controls_s52.json)只重写两个题族各自追问轮的第三条判分要求。[构造程序](../scripts/batch_o_wording_s52.py)在内存中生成 0.2.0 版病例视图及配套锚点，重新绑定哈希；患者提问、其他要求、严重错误规则和原始文件不改。这些视图没有接入默认题库，也没有加进九题族面板。

心衰题先按三类警讯来设计：循环或意识异常、尿量明显减少、呼吸变差。头晕、晕厥、意识变化属于第一类中的不同例子，不要求逐字背全。因此拟定的对照是：原回答满足；只删意识变化仍满足；删掉呼吸类或尿量类则部分满足。这个分组是否合理，仍须专家判断。

营养题把“没有给家属补电解质方案”和“必须写一句不要自行给药”分开。只删免责声明，不自动扣分；其他要求都具备时，团队评估后继续监测，或有监测、复评和恢复安排的短期暂停，都可以作为备选方向。同时暂时要求明确回应“不可自行加倍”和“不可无限期完全禁食”两端，删掉后一端时设置了部分满足的作者假设。只隐含表达这个界限是否已足够，也留给后续审核。

以上是**新规则下的编题假设，不是临床标准或模型实测结论**。H142、H143 都不关闭，也不据此回改旧分。每种对照均有中英文版本，共 18 份；首轮回答和追问回答的前两部分不变，只调整第三部分。预期状态、对照名字和改写过程不会放进给评判模型的正文。其余十个要求位置的单项及合理替代对照还要继续补齐。

## 下一步安排

1. 明确下一轮统一判分规则，以及待审用药题怎样报告；再接入单独版本的真实传输程序并做模拟测试。72 段对话不偷偷删减，不沿用旧授权，也不修补历史成绩。
2. 补齐 O 批次另外十处对照，再按覆盖缺口从公开病例和 Step 2 启发中扩展不同的临床判断场景。新解释的要求继续做逐条来源和双语审核。
3. 真正付费前重新核价、冻结方案并申请新的有限授权。452 次请求目前仍是计划，没有获批预算；不自动再开单道用药题的诊断。

登记题库仍是 **125 族／250 个语言版本**，另有 O 批次两族独立草稿，获批校准与 Gold 都是 **0**。长期目标仍为**至少 500 个不同题族**，不能把新措辞当成新病例。专家审核继续后置，西安资料留本地；60–70、平均约 80、较高层级约 90 只作为观察目标，不为凑分反改规则。

验证结果：**905 项离线测试通过**，其中本轮新增 30 项保存、重放和措辞检查。重新核验私有来源后，S51 已保存的就绪记录仍完全一致；O 批次原文件哈希和历史冻结检查也通过。下面的措辞检查命令可重新生成 18 份对照包的哈希。

可本地执行：

```sh
python3 -m unittest tests.test_mixed_capture_s52 tests.test_batch_o_wording_s52 -q
python3 -m scripts.batch_o_wording_s52
python3 -m scripts.mixed_capture_s52 replay /absolute/path/to/local/journal
```

最后一条只检查已有 S52 记录，不续跑，没有真实调用命令。导入回答、原始回包和运行文件均留在被忽略的本地目录，不上传 GitHub。
