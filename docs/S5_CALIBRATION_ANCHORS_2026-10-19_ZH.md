# S5 前瞻性校准锚点包 — 2026-10-19

六个有来源的患者双轮校准**作者草案**，现有暂定的[逐条件评分锚点](../data/calibration/criterion_anchors_v1.json)和[双语回答对照](../data/calibration/response_contrasts_v1.json)。12 个案例／语言版本均绑定精确内容哈希。每条必要行为都有可观察的 `met`（满足）、`partial`（部分满足）、`missed`（未满足）和可接受等价表达；`unclear`（不明确）需提交人工复核。每种语言另有一个共同的安全首轮回答，以及预期分别为优秀、安全但不完整、不安全的三个后续回答，共 **12 个首轮示例和 36 个后续示例**，不是 48 条已评分观察。对照中的部分满足目标索引标出主要预期遗漏，不保证该答案只遗漏一项。

这些示例是**作者假设，不是经独立裁决的真值**。本次没有调用候选模型或评判模型、没有给数值分数、没有改量表，也没有升级任何案例。预期的“优秀 > 部分正确 > 不安全”顺序以后必须对照合格的人工标签验证，尤其要检查所谓部分正确的答案是否本身也不安全。英文锚点描述同时绑定英中文案例哈希，但这不能证明中文语义等值；中文回答示例亦需合格的语言及临床审核。

离线[校准验证器](../benchmark/calibration_drafts.py)核查案例／语言覆盖、精确案例哈希、条件数量、不同的回答示例、有效的目标条件索引，以及双语一致的重大错误 ID。[案例集审计](../benchmark/portfolio_audit.py)还核验锚点及对照的规范化哈希，并确保六题不进入默认开发集。这些检查**不能**判断临床正确性、翻译质量、真实质量排序，或与 104 道公开题之间的语义重叠。已批准校准和隐藏 Gold 均为 **0**；唯一的本地 Git 忽略隐藏草案继续隔离，本次未为锚点包查看或评分。

锚点界限参考了各题[来源台账](../data/calibration/provenance_batch_b.json)及早前的[丙戊酸来源记录](../data/calibration/provenance_v1.json)，但来源不能认可具体回答措辞或错误级别。[人工审核交接文件](CLINICAL_REVIEW_HANDOFF_ZH.md)中的 H41、H43–H48 列出逐题与逐回答待裁决事项。用于调校评判之前，审核者应逐条把条件与示例标为接受、修改或拒绝，裁决危险错误阈值，独立检查两种语言，并把决定绑定精确哈希。随后才能冻结锚点包，用盲评的 Gemini／Grok 测量条件遗漏、危险答案误通过、满分比例、评判分歧和英中差异。如果评判与已审核标签不符，应调查题目或评判，而不是为凑低／中／高档约 60–70／80／90 的目标而改分数。

[OpenAI 官方评测建议](https://developers.openai.com/api/docs/guides/evaluation-best-practices)强调用人工反馈校准自动指标；其[评分器指南](https://developers.openai.com/api/docs/guides/graders)建议使用优秀／一般／较差的多样回答及真值分数。这里只借鉴流程，未使用 OpenAI 托管评测服务。
