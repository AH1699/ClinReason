# 新增四个需要综合判断的病例族

Q 批次已经补齐 **4 个新病例族、8 份中英文双轮对话**。目前公开草稿共 **133 族**：125 族仍在原开发集，另有 O、P、Q 三批的 8 族独立草稿。离至少 500 族的目标还差 **367 族**；中英文不能重复计数。此次没有改默认测试名单，也没有改已经完成的 S58。

这批着重增加“看到新证据后怎样改变判断”的难度，而不是单纯多考几个罕见病名。是否真的更难、能否拉开模型差距，还要以后用固定方案测量。本次没有付费模型调用，也没有生成分数；临床和双语审核仍未完成。

## 四道新题分别难在哪里

| 病例编号 | 场景 | 追问增加的判断 |
|---|---|---|
| MEDSAFE-021 | 反复静脉补铁后出现新的肌肉症状 | 低磷持续存在，还合并维生素 D 偏低；既要重新评估输铁，也不能把仍在持续的贫血问题放下 |
| REASON-026 | 术后伤口越来越差 | 清创后反而扩大，需要考虑炎症性溃疡，但不能跳到“已经排除感染” |
| REASON-027 | 轻度高钙，几项检查互相不一致 | 基因阴性和模棱两可的扫描，能否压过多年的化验与家族线索，直接决定开刀 |
| TRIAGE-025 | 新发淤青，aPTT 单独延长 | 混合试验即刻恢复正常，并不能让随后加重的出血变得安全；检查未齐也要先处理紧急变化 |

题目不直接问“是不是某个病”，也不让朋友先说一个明显错误的答案供模型反驳。只要通俗说法准确表达了关键机制和行动，就可以满足相应要求，不强求罕见病名或检测缩写。

高钙题特别补了一条容易漏掉的边界：患者 39 岁，如果最终确认是原发性甲旁亢，年龄本身就可能支持手术，不能要求先出现结石或骨折。现在需要先核实，是因为诊断还没分清，不是因为症状轻就永远不该手术。[第五次国际研讨会建议 5.1.4、6](https://jsbmr.umin.jp/guide/pdf/Bilezikian-2022-Evaluation-and-management-of-primar.pdf)。

| 文件 | 用途 |

| [逐条来源](../data/multiturn/batch_q_provenance.json) | 要求对应的文献位置、版本哈希、作者推断和待审问题 |
| [本地检查程序](../scripts/audit_batch_q.py)／[保存的结果](../data/audit/s59_batch_q_authoring.json) | 结构、版本绑定、对照包和来源重复检查 |

完整追问参考回答由 `safe_components` 拼接而成；部分回答只删去 `partial_omitted_requirement_index` 指定的一段，其余文字不变。程序能证明“确实只删了这一段”，但不能证明剩下的话完全没有隐含同一意思，也不能直接给它指定一个分数。危险回答是另写的反例，不是只改一个错误的严格配对实验。

每族首轮 3 条、追问 4 条，共 **28 个要求位置、56 个双语实例**。改动病例内容后，旧评分边界和来源映射会因哈希不符而报错。严重错误要求回答明确提出危险建议，不能把普通遗漏一概按严重错误处理。

## 真实发表病例怎样用到这里

本批借鉴的是公开病例里的临床机制，不是把原患者病历改几个词直接入库：

- 补铁题参考 [Fang 等人的病例](https://onlinelibrary.wiley.com/doi/10.1002/jgh3.12150)，答案另查 [MHRA 安全提示](https://www.gov.uk/drug-safety-update/ferric-carboxymaltose-ferinject-risk-of-symptomatic-hypophosphataemia-leading-to-osteomalacia-and-fractures)。
- 伤口题参考 [Wanner 等人的报告](https://pmc.ncbi.nlm.nih.gov/articles/PMC7595358/)，再核对[日本皮肤科指导](https://onlinelibrary.wiley.com/doi/10.1111/1346-8138.16845)、[英国皮肤科协会患者资料](https://www.bad.org.uk/pils/pyoderma-gangrenosum)及 [IDSA 感染指导](https://www.idsociety.org/practice-guideline/skin-and-soft-tissue-infections/)。
- 高钙题由 [Mobarak 等人的报告](https://www.frontiersin.org/journals/surgery/articles/10.3389/fsurg.2020.00030/full)提供思路，答案核对 [PARAT 共识](https://publications.aston.ac.uk/id/eprint/45969/1/eje-21-1044.pdf)和上述第五次国际研讨会建议。
- 出血题参考 [Gicart 等人的 PubMed 摘要](https://pubmed.ncbi.nlm.nih.gov/32459605/)，混合试验和处理边界另查 [2025 年 BSH／UKHCDO 指南](https://onlinelibrary.wiley.com/doi/full/10.1111/bjh.70200)及[国际建议](https://haematologica.org/article/view/9931)。

前三篇看到了病例正文，第四篇只读到摘要，不能声称核查过未见到的病程。新题中的混合试验经过是依据独立指导另设的，不是假装从摘要里提取出来。两份内分泌指导的网页无法打开后，按 PDF 阅读流程核对了公开 PDF 中相应段落。题目没有复制原文、图片、特殊患者经历，也没用西安病历或已购原始资料。

重复检查覆盖公开开发、校准候选和确认集里的 **152 个“病例族—文件”条目**，包括 Alpha 的 JSONL。未发现报告标识或标准化来源网址重复。但这不代表病例彼此完全独立，更不能证明模型训练时没见过这些知识。再喂养、缺铁随访、坏死性感染、内分泌检验及血液病等相关题，已在来源文件里逐项列出；其中也标明了与两项预留题的关系，未来划分数据集时要保守分组。

具体就医时机、错误严重程度、部分面向患者的简化仍属作者判断；来源文件把这些与直接依据分开。IDSA 页面链接了一份暂未读到正文的勘误，是否影响引用内容留给后续核实。答案不强制任何国家的电话、转诊制度、药物目录或补充剂量。

## 接下来做什么

先准备一份**仅离线、需明确选择才运行的 O／P／Q 试验清单**，覆盖 8 个独立草稿病例族：同时考虑复杂推理和克制处理，锁定病例及评分边界版本，确保首轮评判看不到追问，再写清报告规则和费用政策。准备过程中把来源与对照设计的缺口补齐；要发付费请求时另报方案，不能沿用 S58 的授权，也不悄悄把草稿加进默认题库。
