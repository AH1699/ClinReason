# 将 PubMed 用作未来案例来源 — 2026-10-21 入库决定

**结论：可用于发现病例和追踪证据，但不能视为统一转载许可或答案标准。**PubMed 收录文献引文、摘要及文章链接，本身不是可自由复用的患者病历库。已发表病例报告可能描述真实临床事件，但通常是经选择的回顾性叙述，且公开最终诊断。因此适合寻找尚缺的机制和干扰项，不等于可直接变成隐藏评测题或经临床验证的参考答案。参见 [PubMed 帮助](https://pubmed.ncbi.nlm.nih.gov/help/)及 [NCBI API 说明](https://www.ncbi.nlm.nih.gov/home/develop/api/)。

NLM 明确表示**不拥有** PubMed 摘要的版权，也不能替作者或出版商授权。可免费阅读的摘要或全文链接，不等于可转发或改写患者叙述。[NCBI 政策](https://www.ncbi.nlm.nih.gov/home/about/policies/)与 [PMC 版权说明](https://pmc.ncbi.nlm.nih.gov/about/copyright/)要求逐篇核查权利。[PMC 开放获取子集](https://pmc.ncbi.nlm.nih.gov/tools/openftlist/)是可行的初筛，但每篇许可不同。考虑本项目未来可能公开或商业使用，改编时优先选择明确 CC BY 或 CC0 的文章；逐篇核查署名、衍生作品和商业使用条件。不能默认 CC BY-NC 或 ND 许可满足预期用途。批量获取应使用 PMC 允许的 API／数据集，不抓取文章页面；[NCBI E-utilities 指南](https://www.ncbi.nlm.nih.gov/books/NBK25497/)也规定请求频率及识别信息。

**每个拟由发表病例启发的案例族须完成以下入库记录：**

1. 记录 PMID、若有则记录 PMCID、DOI、文章链接、发表日期、核查日期、文章类型、许可条款及链接、更正／撤稿信号。权利不清时不得改编公开文本；文献引文仍可用于选题。
2. 记录文章启发的**临床机制**，以及哪些患者细节是改动或虚构的。不得把摘要、病例叙述、图片、可识别的罕见组合或结局直接复制进候选可见题目。公开文章仅靠改写措辞不能变成真正隐藏题；相关变体须按来源归组并标记泄露风险。
3. 隐私须独立于许可审核。[ICMJE](https://www.icmje.org/recommendations/browse/roles-and-responsibilities/protection-of-research-participants.html)建议省略非必要身份细节，匿名性存疑时取得知情同意。即便原文公开，本项目题目仍应合成化／去标识。
4. **参考答案条件须另由**适用指南、系统综述或其他合适证据支持，说明适用地域、日期、不确定性及单例推广限制。单个罕见结局不能变成通用治疗规则。案例及英中答案条件以后仍须临床与双语审核。
5. 草稿随附来源和许可决定，先保留在公开开发集。不得直接标成校准或隐藏 Gold、宣称评分已获验证，或悄悄加入默认试跑名单。

作为**仅供入库初筛的例子**，[PMID 41562822](https://pubmed.ncbi.nlm.nih.gov/41562822/)指向 [PMCID PMC12821482](https://pmc.ncbi.nlm.nih.gov/articles/PMC12821482/)；这篇急性房角关闭病例报告的 PMC 记录标注 CC BY 4.0。其机制可能启发用药后视力危险信号案例，但我们**没有复制或改编**该文章，也未核实同意情况或临床标签适用性，未新增案例族。不能仅凭这一罕见病例就把表面上的药物关联写成普遍因果结论。

**目前结果：**PubMed 可作为**候选来源发现渠道**，须遵循本政策。S15 未新增 PubMed 来源案例；冻结的 `REASON-015` 评分对照来自既有指南启发的合成案例。下一批扩充可试做少量逐篇核查许可、绑定来源的病例报告启发案例，并另拟指南支持的答案草稿，仍待专业审核。
