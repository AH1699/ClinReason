# S5 前瞻性案例及分数目标检查点 — 2026-10-18

## 决定

成熟评测希望看到的分数格局是：**中档约 80 分**、低档约 **60–70 分**、高档约 **90 分**。现已写入[章程](BENCHMARK_CHARTER_ZH.md)和[校准计划](SCORING_CALIBRATION_PLAN_2026-10-16_ZH.md)，作为诊断性目标，而不是保证或强制的分数分布。模型档位须独立界定；不得为了达到这些数字而改动正确标签或分数。现有四个案例族的公开双语样本太小、内容已暴露、满分过多，不能据此推算这些区间。多项 97–100 分以及单项“要求满足度”下降一级只影响总分 3／5 分，说明需要调查难度和评判有效性，**不是**马上调权重的理由。

## 隔离和质量检查

- `python3 -m benchmark.portfolio_audit` 确认公开案例族仍为 104 个，**已批准校准为 0、隐藏 Gold 为 0**，另外有 1 个独立校准草案。在当前机器还会核验本地隐藏草案的数量和指纹；全新克隆缺少此文件时，检查结果是无法验证，而不是误报通过。
- 审计拒绝案例 ID 重合、校准与公开开发题使用完全相同的来源网址、校准与隐藏题来源网址重合，以及数量或哈希不符。这只是有限泄漏检查；临床机制重叠和论文被模型记忆仍需人工审核。
- 两个新双语数据集都通过现有双轮结构验证；中文版本明确标为 `machine_translation_unreviewed`。均未加入默认模型矩阵路径；隐藏草案从未发给任何服务商。
- 原有题目、锚点、量表权重、分数和安全封顶均未更改。两道新题没有运行或评分。未评分的草案无法证明中档模型将得 80 分。

## 扩大模型样本前的下一关口

1. 独立临床审核者检查每题的场景、来源与评分条件映射、急迫度、可接受替代答案和严重度；双语审核者检查两个版本。修改时提升版本并记录裁决。专业临床审核可暂时作为发布关口，但在完成前这些只能是开发探针，不是临床 Gold。
2. 冻结更大、更平衡的校准批次，并在不看 ClinReason 分数的前提下预先划定参考模型档位。分开看不同轨道和语言，兼顾低急迫度对照、含糊的后续信息、高危失败以及不同来源机制。不能把公开开发题事后改成隐藏题。
3. 来源／标签审核充分后，用独立裁决的回答锚点检查两位 AI 评判，包括自然回答中的遗漏和接近危险边界的答案。量化满分、危险误通过、评判分歧、语言差距与不确定性。之后才可对题目、锚点或规则做有版本记录的*构念有效性*试验；所有比较模型须在同一版本和未触碰的留出集上重跑。
4. 在扩大隐藏分区前，确定有权限控制的私有保存位置及保留／备份政策。当前唯一的本地草案只是原型，不能替代该决定。

下一项重要批次决定是：何时安排合格的临床与双语复核，以及如何治理私有隐藏集，才能让前瞻性草案升级。其间可继续扩充有来源记录的公开开发题，并进行工程审计，但必须明确标示“未验证”。
